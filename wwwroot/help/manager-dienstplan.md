# Manager-Dienstplan

Der Monatsplan für alle **Manager (FIX-M)** — über alle Filialen, ersetzt die alte Excel. Öffnen über die Sidebar **«Manager-DP»** oder die Kachel auf der Startseite.

## Wer darf planen?

- **Sehen** dürfen alle Benutzer.
- **Planen** darf, wer für die Filiale das Häkchen **«Manager-Dienstplan planen»** hat: Filiale → Tab **Unterzeichner** → beim Benutzer anhaken. Admin darf überall planen.

## So planst du

1. **Zelle anklicken** — sie bekommt einen grauen Rahmen.
2. **Kürzel direkt tippen:** `F` `M` `S` `-` `SK` `IV` `P`
3. **Weiterspringen:** Pfeiltasten in alle Richtungen, Enter = eine Zeile runter. Bei eindeutigen Kürzeln (F, M, P …) springt der Fokus automatisch zum nächsten Tag.
4. **Leertaste** blättert durch die Kürzel (F → M → S → …), **Backspace** löscht die Zelle.

Gespeichert wird sofort und automatisch — es gibt keinen Speichern-Knopf.

| Kürzel | Bedeutung |
|---|---|
| **F** | Frühdienst |
| **M** | Mitteldienst |
| **S** | Spätdienst |
| **-** | frei (gelb) |
| **SK** | Shake-Maschine reinigen |
| **IV** | Inventar |
| **P** | Plan |

## Absenzen: NICHT hier erfassen!

Ferien, Krankheit, Unfall, Mutterschaft, **Schulung**, Militär usw. werden **immer beim Mitarbeiter unter Absenzen** erfasst (Mitarbeiter → Tab «Absenzen»). Sie erscheinen im Dienstplan automatisch als farbiges Feld und sind dort **gesperrt** — so gibt es nur EINE Wahrheit, und die Absenz fliesst auch korrekt in den Lohn.

| Farbe | Bedeutung |
|---|---|
| Grün | Ferien |
| Rot **K** | Krankheit |
| Orange **U** | Unfall |
| Violett **MS** | Mutterschaft |

## Feiertage & Schulferien

- **🎉 Feiertage** (Pflege: HR/Admin): gelten **national**, pro **Kanton** oder für **eine Filiale** (Gemeinde-Feiertag). Im Plan: roter Stern ★ in der Filialzeile — Mauszeiger darauf zeigt Datum und Name.
- **🎓 Schulferien** (Pflege: wer planen darf): pro Filiale mit Von–Bis. Im Plan: blaues Band in der Filialzeile.

In beiden Fenstern kannst du oben nach **Jahr und Filiale filtern**; Neues erfassst du über **«+ Neu erfassen»**.

## Auswertung rechts (pro Manager)

| Spalte | Bedeutung |
|---|---|
| **F / M / S** | Anzahl Früh-/Mittel-/Spätdienste im Monat |
| **frei** | Anzahl freie Tage (`-`) |
| **WE** | **OK** (grün) = mindestens ein **zusammenhängendes Wochenende** (Sa **und** So) frei oder Ferien. Sonst **NOK** (rot). |

💡 Die Zahlen aktualisieren sich sofort beim Planen — NOK ist dein Signal, dem Manager noch ein freies Wochenende einzuplanen.

## PDF

**📄 PDF** erzeugt den ganzen Monat auf **einer A4-Querseite** — gleiche Darstellung wie am Bildschirm, mit Legende. Im Vorschaufenster kannst du drucken oder speichern.

## Gut zu wissen

- Die Zeilen sind nach **Filiale (Restaurant-Nummer)** gruppiert; der **GF** steht pro Filiale zuoberst (★, fett).
- Namen erscheinen als «Vorname N.» — der volle Name steht im Tooltip.
- Monat wechseln: **‹ ›** oben links. Jeder Monat ist unabhängig planbar, auch weit im Voraus.
- Wochenenden sind in der Kopfzeile schattiert; die dickere Linie markiert den **Wochenstart (Montag)**.


## Ferienplaner (GF)

Neben der Monatswahl gibt es für Geschäftsführer den Button **Ferienplaner** —
ein Schwester-Kalender nur für die Ferienplanung der Manager:

1. Mit der Maus über mehrere Tage **ziehen** (oder Klick auf Start- und
   End-Tag) → ein **oranger Balken** = geplant. Balken lassen sich verschieben;
   angrenzende Planungen verschmelzen automatisch.
2. Über das Balken-Menü **«definitiv»** setzen → der Balken wird **grün** und
   die Ferien werden als Absenz beim MA eingetragen (erscheinen auch im
   normalen Manager-DP).
3. Rücknahme ist möglich — mit Rückfrage; die Absenz wird dabei entfernt.

## Weitere Neuerungen
