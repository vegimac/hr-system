# Dashboard & To-dos

Das ist dein **Startbildschirm**. Oben die Modul-Kacheln, darunter die **offenen Punkte** der gewählten Filiale.

## Was sehe ich?

1. **Filiale** links in der Sidebar wählen (sonst siehst du die falschen Todos).
2. **Kacheln** — Shortcut zu Mitarbeiter, Lohnlauf, Posteingang, Auswertungen, HR … (je nach Rolle).
3. **To-do-Liste** — alles, was Aufmerksamkeit braucht. Klick öffnet direkt den richtigen MA / Tab.

Es gibt auch die eigene Seite **„To do"** in der Sidebar — gleiche Liste, etwas mehr Filter und Drucken.

## Typische To-dos (und was tun)

| Meldung | Was tun |
|---|---|
| **Mindestlohn unterschritten** | Vertrag öffnen, Lohn anheben — oder Banner **„Verträge anpassen"** nutzen |
| **Lohnsumme fehlt** | Im Vertrag Stundenlohn / Monatslohn nachtragen |
| **QST-Pflicht offen** | MA → Bewilligung QST Bank → „Höchsten Tarif erfassen" oder Behörden-Befreiung |
| **Bewilligung fehlt / läuft ab** | Bewilligung erfassen oder MA per SMS erinnern |
| **Ehepartner-Dokument fehlt** | Pass/C-Ausweis des Ehepartners in Familie verknüpfen (wichtig für QST) |
| **Probezeitgespräch offen** | MA Formulare → Probezeit: Datum + Protokoll verknüpfen |
| **Probezeit endet bald** | Gespräch führen oder Kündigung in Probezeit prüfen |
| **Vertragsende / Austritt** | Austritt sauber erfassen — siehe [Kündigung & Austritt](#austritt) |
| **Verfügbarkeit fehlt** | In easy@work pflegen, dann MA synchronisieren |
| **Nachtarbeit: Untersuchung / Zeugnis fehlt** | Dokumente verknüpfen oder Formulare drucken (Übersicht → Nachtarbeit) |
| **Geburtstag / Jubiläum** | Optional [Moments](#moments) senden |
| **Schwangerschaft / Fristen** | Familie / Schwanger-Tab öffnen, Fahrplan abarbeiten |
| **Zivilstand oder AHV-Nummer fehlt** | In den Personalien nachtragen — gilt auch vor dem ersten Lohn, und auch ohne Quellensteuer |
| **Personaldaten prüfen** | Rückfrage lesen. Stimmt die Angabe, «Stimmt so». Ein echter Fehler wird in easy@work korrigiert. |
| **Anmeldung / Abmeldung Ausgleichskasse** | [GastroSocial → AKIS](#gastrosocial), Zeile abhaken wenn im AKISnet gemeldet |
| **Schulung fehlt, läuft ab oder ist abgelaufen** | MA → Training, Verfügbar, Statistik. In FRED abhaken oder Nachweis hochladen. |
| **Ferienkürzung möglich** | Absenzen-Tab, Karte Ferienkürzung — nach dem Dienstjahr, oder beim bevorstehenden Austritt |
| **E-Mail unzustellbar** | Adresse am MA korrigieren. Eine harte Rückmeldung («existiert nicht») sperrt den Versand, bis die Adresse stimmt. |

## Banner „Mindestlohn — Verträge anpassen"

Wenn der L-GAV (oder der kommunale Mindestlohn) ab einem Stichtag steigt, erscheint ein Banner:

1. Banner öffnen → Liste der betroffenen Verträge
2. Neuen Lohn prüfen / anpassen (Minimum ist vorausgefüllt)
3. **Übernehmen** — legt pro MA einen **neuen Vertrag ab Stichtag** an (alter Vertrag endet am Vortag)
4. Optional: Mitteilung ins MA-Postfach

Das dürfen **HR / Admin** ausführen. Details: [Mindestlöhne](#mindestloehne).

## Täglicher Rhythmus (Vorschlag)

**Geschäftsführer:** Dashboard prüfen → To-dos abarbeiten → Posteingang leeren → Lohnlauf (wenn Mitte/Ende Monat).

**HR:** Dashboard aller Filialen → QST/Bewilligung/Dokumente → Lohnlauf HR-Schritte → Formulare im [HR-Bereich](#hr-hub).

**Buchhaltung:** Nach Definitiv-Abschluss → [Fibu](#fibu).


## Meine Einstellungen (⚙ unten in der Sidebar)

Jede Benutzerin / jeder Benutzer kann selbst festlegen:

- **Startseite**: welche Seite nach dem Login erscheint (Dashboard, To-do,
  Mitarbeiter, Lohn, HR-Hub … — alle Sidebar-Seiten wählbar).
- **Passwort ändern**: neues Passwort direkt im selben Dialog setzen
  (mind. 8 Zeichen).
